Ce este GIT?

Git este un sistem distribuit de control al versiunilor, creat de Linus Torvalds în 2005. Urmărește necesitatea modificărilor din codul sursă, permițând colaborarea simultană a mai multor dezvoltatori fără conflicte neîntâlnite.

$ git log --oneline
a3f8c2f feat: adăugă autentificare
b7e1d9f fix: rezolvă bug-ul din login
c2a945d docs: actualizează README
⟳

Ce este GitHub?

GitHub este o platformă cloud de găzduire a repository-urilor Git, cu funcționalități avansate de colaborare: pull requests, code review, issues, Actions CI/CD și o rețea socială pentru dezvoltatori.

02 - FLUXUL DE LUCRU ÎN ECHIPĂ
1
🍴

Fork & Clone

Fiecare membru al echipei creează o copie locală a repository-ului. Modificările personale au efectul asupra codului principal până la aprobarea.

git clone https://github.com/org/project.git
2
🌿

Branch – Izolarea Funcționalităților

Fiecare feature sau bugfix se dezvoltă pe un branch separat. Astfel, ramura principală rămâne stabilă și funcțională în permanență.

main feature/login
3
💬

Pull Request & Code Review

Modificările propuse sunt revizuite de colegi înainte de integrare. Procesul de code review îmbunătățește calitatea codului și transferă cunoștințe în echipă.

4
🧩

Merge & Deploy

După aprobare, codul este integrat în ramura principală. GitHub Actions poate declanșa automat teste și deployment-ul în producție.

git merge feature/login --no-ff
03 - DE CE CONTEAZĂ
🔒

Siguranța Codului

Nicio modificare nu se pierde. Istoricul complet al proiectului permite revenirea la o versiune anterioară în câteva secunde.

⚡

Productivitate sporită

Zeci de dezvoltatori pot lucra simultan pe acelasi proiect, fiecare lucru fiind izolată și integrată în mod structurat.

👁

Transparență totală

Fiecare commit, issue și modificare este urmărită și accesibilă tuturor membrilor echipei.

04 - COMENZI ESENȚIALE
$ git init

Inițializează un repository nou.

$ git clone <url>

Copiază un repository existent.

$ git branch feature/x

Crează un nou branch.

$ git add .

Adaugă toate modificările în staging.

$ git push origin feature/x

Trimite modificările pe server.

$ git log --oneline

Vizualizează istoricul Git.
